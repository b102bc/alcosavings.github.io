# Трезвый счёт

Личный iPhone-first PWA-трекер экономии. Статический сайт без сервера, сборки, платных сервисов и регистрации. Все настройки и покупки остаются в локальном хранилище браузера.

## Запуск

Для быстрого просмотра откройте `index.html`. Расчёты и локальное хранение доступны сразу. Чтобы проверять установку PWA и работу офлайн, откройте папку через любой локальный сервер или опубликуйте её на HTTPS-хостинге.

## Как считаются показатели

- Расчётная экономия = средние расходы за неделю × число дней с даты начала / 7.
- Чистая экономия = расчётная экономия − сумма записанных покупок.
- Остаток до цели = максимум из нуля и (цель − чистая экономия).
- Прогноз использует дневной темп (средние расходы за неделю / 7), поэтому это оценка, а не гарантия.
- При нулевом среднем расходе прогноз даты не показывается. Покупки учитываются по общей сумме, независимо от даты.

При старте дата по умолчанию — сегодня, цель — 50 000 единиц выбранной валюты, недельные расходы — 0. Настройки можно изменить в любое время; при изменении даты начала пересчитывается оценка.

## Бесплатная публикация: GitHub Pages

GitHub Pages подходит для личного статического проекта и выдаёт HTTPS-адрес вида `https://имя-пользователя.github.io/имя-репозитория/`.

1. Создайте бесплатный аккаунт GitHub, если его ещё нет, и новый публичный репозиторий, например `trezvyi-schet`.
2. Загрузите в корень репозитория файлы `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js` и `README.md`.
3. В репозитории откройте **Settings → Pages**, выберите публикацию из ветки `main`, папки `/(root)`, и сохраните.
4. Дождитесь появления ссылки на странице Pages и откройте её в Safari на iPhone.
5. В Safari нажмите **Поделиться → На экран «Домой»**. Запускайте трекер с добавленного значка.

Услуга Pages бесплатна для публичных репозиториев на бесплатном GitHub-плане. Если репозиторий будет приватным, перед использованием проверьте доступность Pages в текущем тарифе GitHub.

## Резервная копия и приватность

В разделе «Данные и резервная копия» можно скачать JSON-файл или импортировать прежнюю копию. Импорт заменяет текущие данные. Хранилище привязано к браузеру и устройству: очистка данных Safari удалит записи, а установка приложения не синхронизирует их между устройствами. Экспортируйте копии регулярно и храните файл в выбранном вами месте, например в Яндекс Диске.

Для восстановления откройте приложение на устройстве и нажмите «Импортировать копию». Никакие записи не отправляются в Яндекс 360 или на хостинг автоматически.

## Обновление приложения

Замените файлы в опубликованном репозитории. Service worker обновит кэш при следующем обращении к сайту. Локальные данные хранятся отдельно от файлов сайта.
